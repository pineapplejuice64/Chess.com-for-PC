# Chess.com-for-PC
Updated Chess.com from JariusSW

The original release https://github.com/JairusSW/Chess.com was last updated 4 years ago and there were no hopes for any more updates so I decided to do it myself and help those who might need it too.

# Chess.com Desktop App
Run chess.com on your desktop

## Developing

### Run
```
$ npm install
$ npm start
```
##### Developer Mode
```
$ electron . --dev
```
### Distribute

```
$ npm run make
```
